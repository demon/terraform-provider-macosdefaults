# Examples

These are inlined into the generated docs by `tfplugindocs`, which picks up:

- `provider/provider.tf`
- `data-sources/<name>/data-source.tf`
- `resources/<name>/resource.tf` and `import.sh`

Other `.tf` files here are ignored by the doc generator.

You can also run them on a Mac, but they change your real preferences. Read them first, and
`terraform destroy` afterwards.
